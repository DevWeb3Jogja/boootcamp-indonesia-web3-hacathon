# Aturan Bounty — Dokumentasi Backend Papan Sayembara

Bounty ini dibayar kalau kamu mengirim **dokumentasi backend** yang memenuhi semua kriteria di bawah.

## Kriteria wajib

1. Menjelaskan **cara menjalankan** backend (perintah install dan perintah run).
2. Memuat **daftar endpoint REST** beserta method (GET/POST) dan penjelasan singkat tiap endpoint.
3. Menjelaskan **struktur file/folder** proyek beserta fungsi tiap file.
4. Menyebutkan **konfigurasi environment** yang dibutuhkan (minimal RPC endpoint).
5. Ditulis dalam format Markdown dan bisa diakses publik lewat URL.

## Kriteria nilai tambah (opsional)

- Ada catatan keamanan atau catatan untuk produksi.
- Ada penjelasan arsitektur (alur data dari chain sampai API).

## Cara submit

Kirim URL **raw** ke file Markdown dokumentasimu, contoh:
`https://raw.githubusercontent.com/<user>/<repo>/main/backend/README.md`

Bukti yang tidak bisa diakses publik otomatis ditolak.
